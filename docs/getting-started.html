Getting started

Tutorial: a village supply

A worked example: a village supply from a spring, drawn, analysed, improved and reported, step by step.

This tutorial builds a small gravity scheme: a protected spring feeds a storage tank, which supplies four communal taps. It takes about forty minutes and touches every main part of FlowCHAOS. The values are typical of a rural scheme in Malawi; use your own when you repeat it for a real site.

1. Start a project

  1. File > New. The project uses UTM zone 36 South (EPSG:32736); for a site in another zone, click the coordinate system in the status bar and choose yours.
  2. File > Project Properties > General: name the project "Village supply tutorial".
  3. Press the satellite button on the toolbar and choose a satellite basemap to see the ground. Go to your site with View > Go to Coordinates, or with the place search on the toolbar.
  4. Analysis > Analysis Options > Hydraulics: flow units L/s, head loss formula Hazen-Williams. Leave the rest as it is.

2. Draw the network

The network is drawn in a network layer; the first drawing tool creates one and starts editing it.

  1. Choose Reservoir on the drawing toolbar and click where the spring is. In Element Properties set its Total Head to the level of the spring's water surface, for example 1148 m. Name it Spring.
  2. Choose Tank and click about 850 m below the spring. Set its ground elevation (from the DEM, or type 1132 m), diameter 4.0 m, minimum level 0.3 m, maximum level 2.5 m and starting level 1.5 m. Name it Tank.
  3. Choose Pipe, click the spring, then the tank: the pipe follows your clicks; each click on empty ground places a bend. Double-click, Enter or right-click to finish.
  4. From the tank draw the distribution main to a junction J1, 420 m away, then branches to four taps, Tap1 to Tap4, 200 to 350 m from J1. Type a length (for example 260) and press Enter to place a point exactly that far.
  5. Select the four taps (Ctrl+click) and in Element Properties give them a design withdrawal of 0.15 L/s each (about 13 m3 a day per tap: some 500 people at 25 litres a day).
  6. Ground levels come from a DEM or online terrain automatically (Layer > Ground Elevation Source); check them in Element Properties, and type corrections where you surveyed.

3. Give the pipes their properties

  1. Select the spring-to-tank pipe: material HDPE PE100, internal diameter 79 mm (the 90 mm PN10 pipe), roughness C 150.
  2. Select the distribution pipes with a box (drag across them): main 63 mm pipe (internal about 55 mm), branches 50 mm (internal about 44 mm). The material also feeds the bill of quantities.
  3. Select by Attribute (on the toolbar and the map's right-click menu) selects elements by any property, to change many at once.

4. Run a steady state

  1. Press Run Steady-State (F5). The Simulation Results panel opens and the nodes are coloured by pressure, with a legend on the map.
  2. Click Tap4: Element Properties shows its head, pressure and delivered withdrawal.
  3. In Map Styles, under Links, choose Velocity: the pipes are coloured too.
  4. Open Analysis > Solver Warnings: it should be empty. If not, see Errors and warnings.

Check the pressures: at a communal tap, 5 to 10 m is comfortable; much more wastes water and wears taps, much less gives a weak flow.

5. Make it move through the day

Communal taps are busy at dawn and late afternoon and closed at night.

  1. Analysis > Demand Profiles. Press New Profile, name it TAP, then from Preset choose the communal water point shape. The chart shows the multiplier for each hour.
  2. Select the taps and set their demand profile to TAP.
  3. Analysis > Analysis Options > Times: duration 48:00, hydraulic timestep 1:00.
  4. Analysis > Run Extended Period. The time bar of the Simulation Results panel now steps through 48 hours: press play to watch the tank level and the tap pressures change.
  5. Analysis > Advanced Graphs, Time Series of Tank, Level. A healthy tank fills at night and drains in the day without emptying.

6. Add a control

If the tank overflows at night, close the inlet when it is full:

  1. Analysis > Scheduled Pipe Controls, Start from a Sample, Close the tank inlet before it overflows. The sample is written with your tank and its inlet pipe; adjust the levels if needed.
  2. Run the extended period again and look at the tank's level graph.

7. Check the chlorine

  1. Analysis > Water Quality Analysis, choose Chlorine residual compliance. The spring is the source at 1 mg/L; set the bulk rate from a bottle test if you have one.
  2. Press Run Water Quality Analysis. The summary says whether every tap keeps at least 0.2 mg/L.
  3. Show on Map and play the time bar to watch the chlorine travel.

8. Size the pipes

  1. Analysis > Automatic Pipe Sizing: pipe series HDPE PE100 PN10 (SDR 17), maximum velocity 1.5 m/s, minimum pressure 5 m, peak factor 1.0 (the profile already holds the peaks).
  2. Size Pipes. The table lists the size chosen for each pipe; Apply Sizes writes them into the network (Undo takes them back).

9. Present and price it

  1. Select the pipes from the spring to Tap4 and choose Edit > Longitudinal Profile: the ground, the pipe and the hydraulic grade line along them.
  2. File > Export > Bill of Quantities: pipes by size and material, fittings, tanks and earthworks, priced from your rates.
  3. File > Export > Print Layout: a map sheet with the network, the legend, a scale bar, a north arrow and a title block, exported to PDF.

10. Save

File > Save writes the project with everything: the network, results, styles, layouts and plans. A green bar confirms it. Every step can still be undone with Ctrl+Z.

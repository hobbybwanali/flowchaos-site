User guide

Layers and data

Bring in networks, survey points, drawings, rasters and basemaps, each in its own coordinate system.

Adding layers

Use the Add Layer button above the layers list (or drag files onto the map):

  • Network layer: FlowCHAOS network files (.fcnet), hydraulic model files (.inp, .net), network CSV, shapefiles and KML.
  • Survey points: XYZ, CSV, TXT and spreadsheet files. Points become unconnected nodes with their ground level and every column of the file, ready to label and contour.
  • Raster or DEM: GeoTIFF and other rasters. A DEM can supply ground levels. A PDF drawing or map comes in as an image: choose its page (see Georeferencing below).
  • Vector layer from file (Ctrl+Shift+V): shapefiles, GeoPackage, GeoJSON, KML and DXF drawings as vector layers, every layer and kind of geometry of the file.
  • CAD drawing (DXF): lines, polylines, arcs and splines become a network (see below), or the whole drawing comes in as vector layers (see DXF drawings as vector layers).
  • Surface map: contours and other maps from points or a DEM.
  • Satellite and basemaps: online imagery, street and topographic maps, vector basemaps, your own tile services and offline tile packages.

Networks are layers

Every network is a layer, listed under Networks in the Layers panel: the network of a new project, networks added with Add Layer or File > Import Network > Hydraulic Model, a file dropped on the map, a file opened with File > Open (a new project holding it as its first layer), survey points, and empty layers made with Layer > Add Empty Network Layer. A layer brings everything it needs to run: curves, demand profiles, controls and rules come with it, and names already used in the project are renamed (T1 becomes T1_2) together with every reference to them. The first layer of an empty project also sets the analysis options, times, energy and report settings.

A network layer is changed only while it is being edited, as in a GIS: right-click it and choose Toggle Editing (its name turns bold, with a pencil). What you draw goes into that layer, a new pipe connects only to its nodes, and the other layers stay as they are; an attempt to change them says which layer to edit. Choosing a drawing tool starts editing by itself when it is clear which layer: the only one, or a new one in an empty project; with several layers FlowCHAOS asks.

Right-click a network layer for its menu: Toggle Editing, Zoom to Layer, Attribute Table, labels, Analyse This Network, Export Layer As (FlowCHAOS network, hydraulic model, CSV, GeoJSON, shapefile, GeoPackage, KML or DXF of that layer alone), Rename, Properties and Remove. Right-clicking an element on the map shows the same commands for its layer, under Layer.

A FlowCHAOS network file (.fcnet) holds one network with every property, the profiles, curves, controls and rules it uses, its coordinate system and its look (symbol and labels). Use it to share a network or to add it to another project as a layer; a project file (.fchaos) holds the whole work.

Properties of a network layer has, on its Information page, Show on map switches: junction nodes, tanks and sources, pipes, pumps and valves, and labels. Hiding the junctions shows the pipes alone on a dense network; the hidden elements stay in the network and in the analysis. Hide a layer and its elements leave the map and the analysis; its labels, colours and attribute table are its own (labels follow Map Options until the layer is given its own). After a run the map shows the network that was analysed.

A progress window shows each stage of a long import; what was imported, and any notes, go to the status bar and the log. A message box opens only when something needs your attention.

Networks from lines (DXF, shapefiles, KML, GPX)

Lines become pipes and their ends become junctions. A junction is placed only where pipes meet: at the ends of lines, where lines join end to end, and at a tee, where the end of one line lies on another, which is then split there. Bends stay as vertices of a pipe, so a curved main is one pipe with its true length, not a chain of short pipes. Two pipes that meet end to end with the same diameter, roughness and drawing layer are joined into one. Point features become junctions with their elevation and withdrawal when the file has them.

From a DXF, lines, polylines, 3D polylines, arcs, splines and ellipses are read. The drawing layer of each line is kept as a field; a diameter in the layer name (DN150, D110, 160mm) becomes the pipe diameter, and the heights of 3D polylines become ground levels.

Build Network from Lines

Layer > Build Network from Lines (or right-click a line layer, Build Network from This Layer) makes a new network layer from line layers already in the project. Tick the layers to use (each is highlighted on the map as you choose), and for each one the fields that hold the diameter, roughness, material, name and ground level, with a value to use where a field is empty. Set the snapping tolerance that joins line ends that nearly meet, whether lines are split where another ends on them (tees), and whether a junction is put where two lines cross (untick it when pipes cross at different depths without being connected), and whether pipes that meet end to end with the same properties are joined. Preview counts the pipes, junctions and joins it will make; Generate adds the network as a layer of its own, ready to run. Dropping line files on the Networks group in the Layers panel does the same.

Check and Fix Network

Layer > Check and Fix Network (the second page of the Network Builder) finds what a drawing or an import leaves wrong in a network layer, within a tolerance in metres:

  • pipes that cross with no junction, and pipe ends that lie on another pipe with no junction;
  • ends that run just past the pipe they should join (overshoots) or stop just short of it (undershoots);
  • junctions closer together than the tolerance, pipes drawn twice, pipes with no length and junctions with no pipe;
  • parts of the network with no reservoir or tank (reported for you to decide).

Check lists them; click a row to select the elements and zoom to the place. Fix Ticked fixes the ticked ones together: junctions are put where pipes cross or meet, overshooting tails are cut off, short ends are joined to the pipe, doubled pipes and loose junctions are removed, and levels of new junctions are taken along their pipe. The whole fix is one step that Undo puts back.

Vector layers

Vector layers hold points, lines and polygons that are not a network: plots and parcels, roads, rivers, service areas, valve chambers, survey lines.

New Shapefile Layer (Layer menu, or the first button of the Digitizing toolbar) creates a layer of points, multipoints, lines, multilines, polygons or multipolygons, as a new shapefile is created in a GIS: give it a name, its geometry type, its coordinate system and its fields (text, whole number, decimal number, date or yes/no). A new layer starts with an id field that numbers each new feature by itself (1, 2, 3) and a name field; with Number new features automatically ticked, adding a point does not stop to ask for its values: fill them in later in the attribute table. The layer is written as a shapefile where you choose, or kept in the project only. Layer > Add Vector Layer reads shapefiles, GeoPackage, GeoJSON, KML and DXF files as editable layers (not as a network): a file with several layers, or with points, lines and polygons together, gives one vector layer for each. Vector layers are listed under Vector layers and saved with the project (the layers read from one file, such as the drawing layers of a DXF or the tables of a GeoPackage, sit under a group named after the file, which shows or hides them together); right-click one to reproject it to another coordinate system.

DXF drawings as vector layers

A DXF added as a vector layer asks which of its drawing layers to bring in, and comes in as the drawing is organised: one vector layer for each drawing layer and kind of geometry (points, lines, polygons), or one for each kind when the drawing layers are not split. Blocks are drawn where they are inserted, texts become a labelled point layer at their height and angle, and every feature keeps its drawing layer, line type, colour and handle, with the colour of the drawing on the map. 3D entities keep their elevation in a field, so contour lines of a survey keep their level and can make a DEM. A DXF does not say its coordinate system: choose the one its coordinates are in.

Selecting features

The Select Features button (on the Selection toolbar, and in Vector > Selection) selects the features of any vector layer, whether it is being edited or not. A click on it selects in the way last chosen; the arrow beside it opens every way to select:

  • Select by Click or Box: click a feature, or drag a box over several.
  • Select by Drawn Polygon: click the corners of a polygon; a double-click, Enter or a right-click selects what it touches.
  • With either, Shift adds to the selection, Ctrl takes from it (Ctrl and a click on a feature that is not selected adds it), and Esc clears the selection.
  • Select by Expression (area_ha > 2 and crop == 'maize'), Select by Spatial Relation (the features that intersect, lie within, contain, touch, cross, overlap, are apart from or are near the features of another layer, or only its selected ones), Select All, Invert Selection and Clear Selection.

There is one selection tool for vector layers: it selects in any layer, and in the layer being edited the selected features are the ones Delete, Move, Split and the Advanced Editing commands work on. The network has its own, Select Network Elements, on the Navigate toolbar.

Features are picked from the vector layer chosen in the Layers panel, or from every visible vector layer when none is chosen. Selected features are drawn in the selection colour, and the attribute table and the tools that work on "only the selected features" use them.

Processing tools for vector layers

The Vector menu (and the Processing Toolbox) has five groups of tools for vector layers. Each reads a layer (all its features, or only those selected on the map), works in metres for any coordinate system, and gives its result as a new vector layer, a selection or a table:

  • Measures and Summaries: Field Summary, Totals by Class, Points per Polygon, Line Length per Polygon (pipes in each block), Distance to Closest Feature, Crossing Points, Centre of Features.
  • Overlays: Offset Zone (a band at a distance around features), Cut to Outline, Common Parts, Cut Away, Combine Polygons, Parts Not Shared, Fuse Features, Enclosing Outline, Cut along Lines.
  • Shapes and Conversions: Centre Points, Outlines of Polygons, Fill Closed Lines, Break Lines into Segments, Reduce Vertices, Round Corners, Add Vertices, Points at Intervals (with chainage), Vertices as Points, Size and Position Fields, Bounding Rectangles, Split Multipart Features, Repair Shapes, Supply Zones around Points (the area each junction or well serves).
  • Selection and Sampling: Select by Spatial Relation, Filter by Spatial Relation, Random Sample, Filter by Expression, Copy Selection to New Layer, Layer Footprint, Square Grid, Scatter Points in Polygons.
  • Tables and Layers: Append Layers, One Layer per Value, Link Tables by Field, Link Attributes by Position, Change Coordinate System, Remove Repeated Shapes, Number Features, Drop Field, Field Calculator.

Editing

Select a vector layer in the Layers panel: Toggle Editing and Open Attribute Table on the toolbar act on it (they are greyed until a vector layer is selected). Choosing a Digitizing tool with a vector layer selected starts editing it. While a layer is edited the Digitizing tools work on it:

  • Add Feature: click the vertices; a point needs one click, and a line or polygon is finished with a double-click, Enter or a right-click. Backspace removes the last vertex, Esc drops the sketch, and with Shift held the new part is added to the selected feature of a multi layer. A new feature is numbered automatically and nothing is asked: a layer edited for the first time without a numbering field gets an id field (1, 2, 3 in the order of its features), and each new feature takes the next number. A field all the layer's features share one value of (a drawing layer's name) is filled in too; the rest are filled in the attribute table. An id typed by hand must be free: one used by another feature is refused, with the next free number. A layer can ask for the values with a form instead (its Properties > Fields page).
  • Selecting: the Select Features button of the Selection toolbar; Delete removes the selected features of the layer being edited.
  • Move Feature: drag a feature; it follows the pointer and lands where you release it.
  • Vertex Tool: drag a vertex to move it (the shape follows it as it moves), double-click a segment to add a vertex, right-click a vertex to remove it.
  • Split Features: select the polygons or lines to cut (or none, to cut every one the line crosses), choose Split Features, then click a cutting line across them, starting and ending outside them, and finish it with a double-click, Enter or a right-click. Each piece keeps the attributes; Undo puts the feature back whole. With snapping on, the clicks jump to nearby nodes and grid points.

Advanced Editing (the dropdown beside Delete) has Merge Selected Features (one feature from the selected ones, keeping the attributes of the one you choose), Separate Parts (each part of a multipart feature as a feature of its own), Simplify Selected Features (fewer vertices, within a tolerance in metres), and Copy Features and Paste Features, which bring features from one layer into the layer being edited, with fields matched by name and the coordinates moved into its system. Dissolve, union, clip and the other overlays are in the Processing Toolbox.

Save Layer Edits writes the layer back to the file it came from when that file can be written (a shapefile, GeoPackage or GeoJSON). A layer drawn in the project, or read from a drawing or KML, is a temporary layer: its edits are saved in the project and in a temporary file, without asking for a file name; Save Layer As makes a file of it. Toggle Editing to stop asks to Save the edits, Discard them (the layer goes back to what it was when editing started) or Cancel (keep editing). Every edit is one step of Undo.

Pieces made by Split Features, Separate Parts and pasting are numbered: the layer's numbering field (or a whole-number field called id, fid or objectid) takes the next free numbers, so nothing is asked and no number repeats. A cutting line drawn a little short of a polygon's edge is drawn on to it.

Writing expressions

Expressions (the Update bar, the Field Calculator, Select by Expression, Find and Query) name fields as they read, in any case: area_ha * 1.3, "Design withdrawal (l/s)" * 4 / 2 (double quotes for a name with spaces or brackets), design withdrawal (l/s) * 4 / 2 or design_withdrawal_(l/s) * 4 / 2. 'Single quotes' are text. Type two letters, or a double quote, for a list of the fields and functions that match; while typing in the Update bar, a click on a column heading or a cell puts that column's field into the expression, as a spreadsheet takes a cell into a formula.

Every expression is checked as it is written: a green tick (and the line under the Expression Builder's box) when it can be worked out, with what the first row gives; a red cross with what is wrong, such as an unknown field or a bracket left open. In the Expression Builder the functions show in bold teal, fields in orange, text in green and numbers in purple. The Update list names every column: those that cannot be set (measured from the shape, or worked out by the analysis) are greyed, with the reason, and can still be used in the expression.

Attribute table

The attribute table lists every feature with its values and its calculated fields: length_m for lines; perimeter_m, area_m2 and area_ha for polygons, holes left out. They are measured on the ellipsoid, the true ground values a GIS gives, or on the map grid when Project Properties > Measurements > Measure areas says so (a UTM grid is up to 0.1 % off the ground near its central meridian, more towards the edges of its zone). They are worked out from each shape, always current (shown in grey), and can be used like any other field to colour the layer, label it and in expressions. Large layers open at once: rows are drawn as they come into view.

  • Selecting: click rows, with Ctrl or Shift to add more; Select by Expression (with the Expression Builder, as a new selection, added to it, taken from it or within it), Select All, Invert Selection and Deselect All. The table and the map share one selection.
  • Finding: type words in the find box, or tick Selected features only; the status line counts the features, the selected ones and those shown.
  • Columns: click a heading to sort (numbers as numbers); right-click a heading to sort, fit, hide or show columns. Double-click a row number to zoom the map to that feature.
  • Editing: Toggle Editing opens the cells for typing and keeps the table in front. The Update bar sets a field from a value or an expression (area_ha * 1.3, if(crop == 'maize', 2, 1)) for the selected features or all of them. Delete Fields removes several fields at once (Tick All for a fresh start); the id field stays, so new features keep their numbers, and Add Field adds your own. Add Field, the Field Calculator and the Delete button (its menu has Delete Selected Features and Delete Field) complete it; every change is one step of Undo, and Save Layer Edits writes the layer to its file.
  • Copy Selected Rows (to paste into a spreadsheet) and Save Selected Features As a new file.

The Field Calculator fills a new or an existing field from an expression of other fields, for example area / 10000 for hectares or concat(name, ' ', zone). It knows + - * /, brackets and round, abs, min, max, int, float, str, len, sqrt, upper, lower and concat, and can update the selected features only.

Properties

Double-click a vector layer (or right-click, Properties) for its properties:

  • Information and Source: the geometry, the number of features, the extent, the file.

  • Symbology: a single symbol, categorized (one colour for each value of a field) or graduated (classes of a number field). The symbol has a stroke colour, width and style (solid, dash, dot, dash-dot), a fill colour, opacity and style (solid, hatched, cross-hatched, diagonal, dotted or none), and for points a marker (circle, square, triangle, diamond, star, pentagon, hexagon, cross or X) and a size.

    Classes take their colours from a colour ramp: ramps for values (from light to dark, or two colours around a middle), sets of distinct colours for categories, or random colours; Invert turns a ramp round, and changing the ramp recolours the classes at once. Graduated classes are made by equal intervals, equal counts (quantiles), natural breaks (Jenks: similar values kept together), standard deviation or round numbers, with the number of classes and the decimals of their labels.

    The buttons above the class table: Classify (categories add the values not listed yet; graduated classes are made again), Add Class, Delete Class, Delete All Classes, Show All and Hide All. In the table, untick a class to hide it, edit a value, a range or a label in its cell, and click a colour to change it; Features counts the features in each class. The ramps are kept in style/colour_ramps.json in the reference data: add your own there.

  • Labels: a field, the font, size, colour, bold, a halo and the placement (over, above, below, right or left of the feature). A polygon's label sits at the point deepest inside it; a label that would cover another is left out until you zoom in, unless Show every label is ticked.

  • Fields: the fields with their types.

  • Display: the scales the layer shows at.

  • Metadata: author, abstract and keywords.

Apply shows the change at once; OK keeps it.

Georeferencing and tracing a map or drawing

Layer > Georeferencer places a scanned map, a drawing, a photo or a page of a PDF on the map. A PDF asks for its page first: every page is shown as a preview with its sheet size (A1 landscape, for example), and the chosen page is drawn on white at 150 to 400 dpi and kept as an image beside the PDF. There is one Georeferencer window: it opens empty, or with the image chosen in the Layers panel, and Add Image loads another. Opening another image (or the practice map) asks first whether to save the point pairs of the one shown.

  1. Add Point: click points on the image (grid crossings, road junctions, building corners). Each click adds a row to the table; the window stays where it is, so you can add all the image points first.
  2. Select a row and click Pick Map Point: the main map comes forward, click the same place on it (or type its coordinates in the table), and the window comes back with the next row waiting.
  3. Pick on Map Only works on the main map alone: click a point of the overlaid image, then where it belongs, pair after pair; the window returns when the chosen method has the pairs it needs.

The table shows each pair with its residual and the fit its RMS error. Delete Point (or the Delete key) removes the selected pair. Undo and Redo (Ctrl+Z, Ctrl+Y) step back and forward through the pairs and the placement; Place in View puts the whole image in the middle of the map as a starting position, and Reset Placement returns it to where it was when opened. The second row of buttons keeps the result: Load Points, Save Points, Save World File and Export GeoTIFF (a georeferenced copy of the image, added as a layer). When it fits, Trace Over Image keeps the image faintly under the network and starts the pipe tool, so the network is drawn along the lines of the image. The image's Layer Properties have a Georeferencing page with its state.

To learn it, open File > Open Sample Projects > Georeferencing practice map (or the Practice Map button): a scanned-style sheet with a coordinate grid in UTM zone 36 South. Load Points with practice_map.points beside it for nine pairs at grid crossings, or add your own by typing the grid coordinates written on the sheet.

Basemaps

Layer > Basemaps and Satellite Imagery (or the satellite button) adds online maps under the network:

Group Basemaps
Satellite imagery Esri World Imagery, Esri Clarity, Esri Firefly, Google Satellite, Google Satellite Hybrid, Bing Virtual Earth
Street maps OpenStreetMap, Esri World Street Map, Carto Positron, Dark Matter and Voyager, Google Maps
Topographic and terrain Google Terrain, Google Terrain Hybrid, OpenTopoMap, Esri World Topographic, Hillshade, National Geographic
Vector basemaps ESRI Colored Pencil, Dark, Modern Antique, Nova, Night, Topo, Charted Territory, OSM Standard, OSM Street, OSM Light Grey, OSM Dark Grey, OSM Blueprint
Labels and overlays place names, boundaries and roads to put over imagery

Vector basemaps are drawn from map data with their own style (patterns, line styles and labels), so they stay sharp at every zoom. Tiles are kept on disk, so maps already seen also work offline. Respect each provider's terms of use; any other service can be added as a custom tile address with {z}, {x} and {y} (or {q} for quadkey services). Once a day FlowCHAOS checks in the background that every catalogue service still answers; one that has been retired is greyed out in the menus.

Measuring

The Measure button measures distances, areas and perimeters, and angles and bearings. The Measure panel, under Element Properties, shows the values without covering the map, with the units to use: metres, kilometres, feet, yards, miles, nautical miles, centimetres, millimetres, inches, degrees or map units for lengths; square metres, square kilometres, hectares, acres, square feet, yards, miles, nautical miles, centimetres, millimetres, inches, square degrees or map units for areas; degrees, radians, gradians, mils or degrees, minutes and seconds for angles. Its buttons start again, copy the values and close (clearing the drawing and returning to Select); Esc clears it too. The default units of the project are set in Project Properties > Measurements, with Measure areas: on the ellipsoid (the default, as the areas of vector features) or on the map grid.

Merging networks

Layer > Merge Network Layers (or right-click a network layer > Merge Other Networks Into This) joins other network layers into one. Nodes closer than the join distance become one node; a node of one network lying on a pipe of the other splits that pipe and connects there; ends within the connection distance can be joined by a new pipe. Pipes, pumps and valves that are the same in both are kept once. The report lists what was joined, connected and left apart.

Coordinate systems

The project has one coordinate system (status bar, or Project Properties > Coordinates). A file opened into an empty project keeps its own system: the project takes it, and nothing is reprojected until you choose another system yourself. A network added to a project in another system is transformed into the project's system, and its original system is kept with the layer. When you import points, choose the system they were surveyed in.

Vector and raster layers in other systems are drawn in the project's system as they are. Right-click a vector layer > Reproject Layer to add a copy in another system (save it with Save As), or a raster layer > Save Reprojected Copy. Properties > Coordinate system of a vector layer only changes the system it is read in, for a file that was labelled wrongly.

Layer properties

Double-click a layer (or use the properties button above the list):

  • Symbology: for points (junctions, tanks, reservoirs) the colour, size and opacity; for lines (pipes, pumps, valves) the colour, thickness and pattern (solid, dashed, dotted, dash and dot). A map view, when one is chosen, colours the layer instead.
  • Labels: see Map views, legends and labels.
  • Fields: every field with its type, how many features fill it and an example value.
  • Display: show the layer only between two map scales.
  • Metadata: author and abstract, saved with the project.

Project Properties > Data Sources lists every file the project uses; missing rasters can be pointed at their new location there.

Ground levels

New and moved nodes take their ground level automatically. Choose the source in Project Properties > Elevation: a DEM, online terrain, or none (type levels by hand).

Find and Query

Find and Query (Edit menu, Ctrl+F, or the toolbar) is a tool window beside the map, for network elements and vector features alike.

Find matches names as you type, in all elements, one type (junctions, reservoirs, tanks, pipes, pumps, valves) or one vector layer (any text value of its features), by contains, starts with, exact or ends with, optionally with the links of the nodes found. When the project has several network layers, choose the one to search in, or all of them.

Query runs on the layer you choose, named in full: the nodes or links of one network layer, of all network layers, or a vector layer. A query is made of conditions (a field, a comparison and a value) that must all hold, or any of them, or of an expression such as pressure_m < 10 and node_type == 'JUNCTION' built with the Expression Builder. The comparisons are below, at most, equal to, not equal to, at least, above, between (10 and 20), one of (110, 160, 200 or PVC, HDPE), contains, does not contain, starts with, ends with, is empty and is not empty. Invert finds the ones that do not match. New Query starts again; double-click a condition to change it, and Delete removes it. The label above the matches says exactly what was run and on which layer, and with several networks each match shows the network it belongs to.

Save Query keeps a query by name with the project. Each saved query runs on its own, on its own layer, with Run (or a double-click); Load into the Editor brings it back to change, and saved queries can be renamed and removed.

The matches are listed with the value that matched. Select on Map makes them a new selection, adds them to it, takes them from it or keeps only those already selected; Zoom To, Copy IDs and Export CSV act on the selected rows, or on all of them.

Attribute tables

Attribute Table opens the table of the layer selected in the Layers panel: each imported network layer has its own table, and an open table is brought forward rather than opened twice. Selection is shared with the map both ways: selecting rows selects those elements on the map, and selecting on the map highlights their rows. Edits in the table can be undone like any other edit.

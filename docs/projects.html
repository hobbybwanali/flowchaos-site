Working with projects

Projects and files: starting, opening, saving and setting up a project, and the defaults it uses.

What a project holds

A FlowCHAOS project (a .fchaos file) holds the whole work: every network layer, vector layer, raster and basemap; surface maps and contours; the analysis options, demand profiles, curves, controls and rules; the last results; labels, legends and map styles; print layouts; bills of quantities and construction plans; and the project's own settings. One file is everything another engineer needs to open the work where you left it.

A network file (.fcnet) holds a single network, to share it or to add it to another project as a layer. FlowCHAOS also imports and exports hydraulic model input files (.inp), the format of the widely used public-domain network modelling program, so models can move between programs. It is not a FlowCHAOS format: FlowCHAOS's own files are the project (.fchaos) and the network file (.fcnet) (File formats).

Starting a project

  • File > New starts an empty project in UTM zone 36 South (EPSG:32736). Change the coordinate system in Project Properties > Coordinates, or click it in the status bar.
  • File > Open opens a project, or starts a new project holding a network file as its first layer (.fcnet, .inp, .net, CSV, shapefile, KML, GPX, DXF).
  • File > Open Recent lists the last projects opened.
  • File > Open Sample Projects opens ready networks by discipline: town supply, rural gravity scheme, bulk transfer, chlorine study, building plumbing, georeferencing practice, and irrigation schemes from a 1.5 ha smallholder drip system to a 10 ha banana farm and a 50 ha centre pivot.
  • Files can also be dragged onto the map: a project opens, other files are added as layers.

Saving

File > Save (Ctrl+S) writes the project; File > Save As writes it under another name. The title bar shows an asterisk while there are unsaved changes, and FlowCHAOS asks before closing or opening another project. Every save shows a green bar over the bottom of the window, or a red one with the reason if the file could not be written. Results are saved with the project, so a project reopens with its results on the map.

Auto-save and recovery. While you work, FlowCHAOS writes a recovery copy of the project with its unsaved changes every few minutes (Settings > Auto-save: off, or every 1 to 30 minutes; 5 by default). The copy is kept in FlowCHAOS's own folder, never over your file, and is removed when the project is saved or FlowCHAOS closes normally. If FlowCHAOS stops unexpectedly, the next start offers to Recover the work: it opens as an unsaved project with its own file name, so Save puts it back.

Undo and redo

Every change, from moving a node to applying pipe sizes, is one step of Edit > Undo (Ctrl+Z) and Edit > Redo (Ctrl+Y). The history covers the session; saving does not clear it.

Project Properties

File > Project Properties sets what applies to the whole project:

Tab What it sets
General the project name, title and description, the file, a summary of the network and its flow units
Metadata author, organisation, keywords and an abstract, kept with the project and used in reports
Coordinates the project's coordinate system (CRS), with its details
Measurements how coordinates are shown (metres, degrees and minutes) and their decimals; units of lengths, areas and angles
View the predefined map scales and how the map draws
Data Sources the files the project's layers come from
Elevation where ground levels come from: a DEM, online terrain, or typed values
Analysis the head loss formula, demand model, duration and time step of runs, and the design standard

The design standard sets the starting values of pipe sizing, fire flow, criticality and the withdrawal tools: water use per person, peak factor, losses, minimum and maximum pressure, velocity limits and fire flow. The presets describe typical schemes; check them against the standard that applies to your project, and add your own to design/standards.json in the reference data.

Coordinates

Every project has a coordinate system, and every layer keeps its own: a shapefile in geographic coordinates and a DXF in a local grid are each shown in the project's system without changing the files. Lengths of pipes are true ground lengths in that system. See Coordinates and units.

Defaults for new elements

Settings > ID Labels and Element Defaults sets the names of new elements and the properties they are drawn with (see Analysis options). Draw quickly with sensible defaults, then correct what differs with Select by Attribute and the attribute table.

Where FlowCHAOS keeps your settings

Window layouts, recent files, colour ramps, the language and similar preferences are kept for your Windows account, not in the project. Settings > Language and Region chooses the language of the menus and the number formats. Reference data you add (pipe series, standards, rates, curves) goes in %APPDATA%\FlowCHAOS\data and overrides the data installed with the program.
